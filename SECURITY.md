# Security policy

Report a vulnerability through GitHub's private advisory form for this repository:
[Report a vulnerability](https://github.com/ClawdBuilder/jig-herdr/security/advisories/new).

Do not open a public issue or post a real credential. Include the tag, the Herdr and Node versions, the Jig version if you use the Jig layout, the
configuration without secrets, and what happened instead.

Only the latest release on the Releases page is supported. Move to the latest release before reporting a problem with an
older one.
